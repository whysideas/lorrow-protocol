# Security policy

This is unaudited research software with no supported production deployment. The mock policy is deliberately mutable by anyone. Do not entrust real funds to it.

When the public repository is available, use GitHub's **Security > Report a vulnerability** if private reporting is enabled. If that option is absent, open an issue requesting a private reporting channel without exploit details. No private reporting setup or paid bounty should be presumed from this file alone.

State the affected code/version, expected invariant, observed failure and a local reproduction using test assets. Do not include credentials or personal data. Publication and fixes should be coordinated so real assets are not unnecessarily exposed.

No security guarantees, formal proof or funded bug-bounty program currently exist. Public test results cover the vault with a mock policy, not a complete loan protocol.
